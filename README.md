# xigma-application

Public pages Google requires to publish Xigma's "Sign in with Google": the home page, the privacy
policy and the terms of service. Served by GitHub Pages at
https://xigma-application.github.io/xigma-application/.

| Page             | Address                                                            |
| ---------------- | ------------------------------------------------------------------ |
| Home             | https://xigma-application.github.io/xigma-application/               |
| Privacy Policy   | https://xigma-application.github.io/xigma-application/privacy.html   |
| Terms of Service | https://xigma-application.github.io/xigma-application/terms.html     |

Plain HTML and one stylesheet, no build. Edit a page and push to `main`; GitHub Pages publishes it
within a minute.

In Google Cloud → Google Auth Platform → Branding, use the three addresses above and add
`xigma-application.github.io` to the authorised domains.
